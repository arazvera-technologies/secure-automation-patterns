# Secure Automation Patterns

**Defensive engineering reference | Documentation, not a security product**

A collection of practical design patterns for building permission-aware automation with recoverable actions, auditability, and human oversight.

## Contents
- [Access and approval controls](docs/approval-and-access.md)
- [Defensive response playbook](docs/defensive-response.md)

## Principles
- Keep read, write, administrative and financial privileges separate.
- Use explicit authorization and high-impact approvals.
- Prefer dry-run, rollback, backups and integrity checks before production changes.
- Keep security tooling focused on defense, detection and permitted containment.
- Avoid storing credentials in logs, repositories or conversation history.

This repository contains general guidance only. It includes no real credentials, exploit techniques, private project source code or customer information.
